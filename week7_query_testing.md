# Week 7 SQL Query Development and Testing

## Overview

During Week 7, I continued developing the database project by creating additional SQL queries for basic database analysis. The queries focus on counting students, tutors, subjects, sessions, and attendance records.

## Queries Developed

### Query 1 – Total Students

This query counts the total number of student records in the students table.

### Query 2 – Total Tutors

This query counts the total number of tutor records in the tutors table.

### Query 3 – Total Subjects

This query counts the total number of subject records in the subjects table.

### Query 4 – Sessions by Subject

This query groups sessions by subject and counts the number of sessions associated with each subject.

### Query 5 – Attendance Status

This query groups attendance records by attendance status and counts the number of records for each status.

## Testing

The queries were reviewed for correct SQL syntax and checked against the database structure. The queries use aggregate functions such as `COUNT()` and grouping with `GROUP BY` to produce summary information.

## Development Progress

These additional queries expand the project's analytical capabilities. The results can be used to understand the size of the database and summarize tutoring sessions and attendance activity.

## Next Steps

Future development will focus on testing more complex queries involving joins between students, sessions, tutors, subjects, and attendance records.
